A bug-fix mod for **Surviving Mars: Relaunched**. Every fix in it repairs a
defect verified in the game's own shipped code — not a balance change, not a
redesign, not an opinion.

## Is it safe for my save?

**Yes, including a long-running one.** The mod writes almost nothing into your
savegame, and what it does write is inert without it. You can add it to a save
you have already played for hundreds of sols.

## Will it change how the game plays?

**No.** If the game's code says a Sensor Tower should delay meteors and instead
it attracts them, that gets fixed. If we merely disagreed with a design choice,
it is not in this pack — those live in a **separate, entirely optional mod** you
do not need to install.

## Do I need anything else?

**No.** The fix pack works on its own. The optional-modules mod also works on its
own. Neither requires the other, and they work together.

## The two mods, and which one you want

=== "Community Fix Pack"

    Bug fixes only. **74 modules**, all on by default, no configuration needed.
    This is the one most people want.

=== "Community Opt-In Pack"

    **8 optional modules**, all off by default, each one a deliberate change to
    how the game behaves rather than a repair. You turn on the ones you want in
    *Options → Mod Options*. Install it only if you want something from its list.
