- **MEASURED 2026-09-15 from the live `ModTools\Src`.** The class, and what it is not:
  - `MicroGHabitatBase` — `Lua/Buildings/MicroGHabitat.lua:3-4`,
    `__parents = { "LivingBase", "LifeSupportConsumer", "WaypointsObj", "Community",
    "MicroGHabitatAutoResolve", "FoodBuilding" }`. **No `Dome` anywhere in that list.**
    `NaturalHabitatBase` descends from it, so one test covers Naturalist and Micro-G alike.
  - `grep -rn 'AddToLabel("Dome"' <Src>/Lua` returns **one** line, `Dome.lua:1103`, inside
    `Dome:GameInit`. ⇒ a habitat can never enter `labels.Dome`.
  - `grep -rn 'labels\.Dome\b' <Src>/Lua | wc -l` ⇒ **70**. ⛔ Those 70 are NOT all defects —
    many legitimately mean actual domes (dome cap, placement, dome UI). What is established is
    that a habitat is absent from every one of them; whether each absence is wrong needs reading
    that site. ⛔ **No blanket repair on the strength of this count.**
- ⭐ **It IS community-visible, which is why it is not universally excluded.**
  `Community:GameInit` does `self.city:AddToLabel("Community", self)` (`Community.lua:47`) and
  `accept_colonists = true` is declared on `Community` itself (`:15`), inherited unchanged. Any
  sweep over `city.labels.Community` sees a habitat; any sweep over `labels.Dome` does not.
- ⚠️ **The asymmetry that bites: `CanVisit`.** `Dome` declares **no** override, so it answers
  `Community:CanVisit` — `not self.destroyed and not self.demolishing` (`Community.lua:420-422`).
  `MicroGHabitatBase:CanVisit(colonist)` (`MicroGHabitat.lua:59-73`) adds a capacity test and
  returns `self.free_spaces.inclusive > 0` when called with **no** colonist. ⇒ **a full dome stays
  in a candidate list; a full habitat is dropped.** ⭐ Its early-out —
  `if IsValid(colonist) and (self.reserved[colonist] or table.find(self.colonists, colonist))
  then return true` — is correct for a returning resident but **never fires from a caller that
  passes no colonist**, e.g. `GetDomesReachableByColonists` (`_GameUtils.lua:399`).
  ⚠️ Free space counts reservations as occupied: `Residence:GetFreeSpace` is
  `capacity - closed - (#reserved + #colonists)` (`Residence.lua:232-233`).
- **Dome-shaped API it DOES implement** (so "it will throw on dome methods" is not a safe
  assumption): `GetClusterDomes` (`MicroGHabitat.lua:103`), `ReserveResidence` / `AddResident` /
  `RemoveResident` (`:77-100`), `HasFreeLivingSpaceFor` (`:177-182`),
  `MicroGHabitatAutoResolve:IsSuitable` = `GetScoreFor(colonist) > 0` (`:173-175`), so residency
  is score-gated and re-evaluated rather than permanent.
- **Isolation flags, all on `MicroGHabitatBase`:** `allow_work_in_connected = false` and
  `allow_service_in_connected = false` (`:11-12`), `can_be_safety_dome = false` (`:14`),
  `dome_forbidden` on the templates. Turning a habitat off calls `KickAllColonists` (`:192-203`)
  and anyone who cannot reach a dome is left Stranded.
- ⭐ **Employment already carves habitat residents out, and supplies the predicate.**
  `IsSuitableWorkplace` (`Workplace.lua:1446-1462`) tests
  `IsKindOf(unit.residence, "MicroGHabitatBase")`, then rejects any workplace with a valid
  `parent_dome` and any workplace beyond `unit.residence:GetOutsideWorkplacesDist()`.
  ⚠️ **They are NOT unemployable** — an outside workplace sited near the habitat is a legal job.
  ⛔ Key on `residence`, not `dome`: `Colonist:SetDome(false)` clears `dome` whenever they step
  outside, while a resident's `residence` persists.
- **Build data, which is why it reads as a dome to a player:** both habitat templates declare
  `build_category = "Domes"`; `NaturalistHabitat.lua:26` has `group = "Domes"` so it appears in
  the Domes build menu beside real domes, while `MicroGHabitat.lua:31` has `group = "Asteroids"`
  and does not. ⛔ Menu membership is not class identity — Passage, Passage Hub and Passage Ramp
  share that menu and are not domes either.
- **Falsifier, one command each.** `grep -rn 'AddToLabel("Dome"' <Src>/Lua` must stay at one hit
  in `Dome:GameInit`; `MicroGHabitat.lua:3-4` must still lack a `Dome` parent; `Dome` must still
  declare no `CanVisit`. **Stale if** a patch gives a habitat a `Dome` ancestor, adds a second
  `Dome`-label writer, or gives `Dome` its own `CanVisit`.
