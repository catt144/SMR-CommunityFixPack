- **The fastest PLAYER-REACHABLE game speed is 5×, not the 20× that
  `const.ultraGameSpeed` advertises.** (1.0.7.396349 derivation, citations in that
  tree; the 1.1.1 mechanism is the next bullet.) `const.ultraGameSpeed = 20` is real
  (`Lua\_GameConst.lua:26-28`) but `"ultra"` is appended to the speed-state list
  **only under `if Platform.debug`** (`Lua\X\HUD.lua:462-467`, `:481-487`), and
  the HUD only wires `"play"` / `"medium"` / `"fast"` buttons
  (`Lua\XDef\HUD.generated.lua:226,:247,:269`). Retail speeds are therefore
  **1× / 3× (`mediumGameSpeed`) / 5× (`fastGameSpeed`)** — confirmed in game by
  the fastest button's own tooltip, *"Play at five times normal speed"*.
  ⚠️ **Any real-time-vs-game-time arithmetic must use 5× as the ceiling.** Cost
  a wrong figure on 2026-08-02: an F82 estimate assumed 20×, computed 3.3 sols
  where the truth is 0.83, and wrongly dismissed the owner's own "close to an
  entire sol" report as reading low. **One sol at each retail speed:** 12 real
  min at 1×, 4 at 3×, **2 min 24 s at 5×** (`const.Scale.sols` = 720 000 ms,
  `Lua\__const.lua:1454-1458`).
- **RE-DERIVED on 1.1.1.405907, 2026-09-27: the 5× ceiling HOLDS by a different mechanism;
  the 1.0.7 citations above no longer describe the shipped tree.** 1.1.x moved speed
  handling into `CommonLua/Features/GameSpeed.lua`. `const.GameSpeeds` now carries
  `fastest = const.ultraGameSpeed` (20), but release builds set
  `const.GameSpeedsExcludeFromList = { fastest = true }` under `if not Platform.debug`
  (`Lua/Config/config.lua:117-126`), and the speed-up/down hotkeys step through that list
  (`SetGameSpeed("next")`, `CommonLua/Features/GameSpeed.lua:18-28`, `:56-62`). The HUD still
  wires only normal/medium/fast, whose tooltips say normal, three times and five times
  (`Lua/XDef/HUD.generated.lua:241`, `:262`, `:283`). One sol is still 720 000 ms
  (`Lua/__const.lua:1565-1570`). Source only; the in-game tooltip read is from 1.0.7.
