- **Upload stages and first publication.** `CommonLua/Classes/GedModEditor.lua:785-797`
  calls prepare, local packaging, then its captured upload callback; packaging
  calls `ReloadLua()` at :711. `CommonLua/Libs/Paradox/ParadoxMods.lua:69-75`
  reads an existing Pdx id or uses zero for the details lookup, then performs
  setup. The details error is overwritten, so it is not itself terminal.
  Thumbnail/screenshots and content upload precede publication (:86-115).
  Existing id selects `AsyncPublishNewModVersion`; absent id selects
  `AsyncPdxPublishMod` (:139-164). Id/version writeback and SaveWholeMod occur
  only after a successful publish return (:165-176). No id is not a missing
  credential for a first upload.
- **Field bounds and preflight scope.** `CommonLua/Modding/Mod.lua:243-246`
  declares title max_len 60, long description 8000, and PDX summary 200.
  `ParadoxMods.lua:24-46` checks only empty strings, not these lengths.
  Both publish APIs receive the summary unchanged (:148-164).
  This establishes declared editor constraints, not native/backend validation.
- **The disk log loses the localized error.** `ParadoxMods.lua:57-64` maps an
  empty error string to Unknown error and returns localized concatenation.
  `CommonLua/Core/localization.lua:342-347,377-416` produces translation
  tables; `GedModEditor.lua:779-781` logs the message with %s.
  `Mod.lua:115-130` formats it without translation. Extracted-source desk
  control reproduces a table address while losing the SDK error text.
  The table address therefore does not identify the stage or SDK return type.
  Success calls ModMessage, not ModLog (:801-803), so this path does not itself
  print its success receipt to the disk log.
- **Interception seam and console limits.** Upload's stage globals are read at
  call time; the local publish selection is made immediately before invocation
  (`ParadoxMods.lua:70-73,93-114,139-148`). No earlier file-local binding in
  that caller prevents an outer wrapper. `CommonLua/console.lua:36-56`
  distinguishes the asserts console's real-global access from the retail
  mod environment; PDX/AsyncPdx names are filtered there (:288-293 in ParadoxMods).
  `CommonLua/UI/Dev/uiConsole.lua:20-25` sets input MaxLen 2048.
  `CommonLua/X/XTextEditor.lua:375-386` strips newlines for single-line input
  and rejects insertions exceeding self.MaxLen. These are possible silent-paste
  failure mechanisms, not a diagnosis of an unrecorded historical paste.
