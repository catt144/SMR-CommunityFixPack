### C60 — ranch UI builds a discarded resource-id list (P3, PERF) `[cand 2026-09-10: source-read; profiling required]`

**DIFF-CAUSED. SOURCE intent tell:** computed value is discarded. New
`Lua/Units/Animals.lua` `UIBreedUpdate :1172-1233` allocates `resource_ids` and
fills it at `:1202-1205`; the local is never read or captured. The rollover
closure below obtains `outputs` again. Old `UIBreedUpdate :972-1020` has no
equivalent allocation; its single-Food rollover reads `herd.food` directly.
This is a dead-work tell, not evidence that the game stutters because of it.

**SOURCE ROUTE — R2:** the base ranch panel's
`Lua/XDef/sectionPasture.generated.lua:32-33` context callback invokes
`UIBreedUpdate`. The updater is called for visible breed slots. Both base
InsidePasture and OpenPasture use that panel. **Non-owner answer: yes**,
normal base breeds already supply output lists; DLC content is unnecessary.
Source does not establish how frequently the UI context refreshes in play.

**INFERRED severity:** unnecessary table allocation and iteration while the
panel updates. Any effect on frame time is unmeasured and may be negligible.
This cannot explain the original FR-3 report by itself: that report predates
1.1.0 and the allocation. No gameplay state or balance change is implicated.

**Independent recipe [NEVER RUN]:** on a fresh colony with a functioning ranch,
open its panel during normal simulation and record callback counts, allocation
samples and frame times; compare the same interval with the panel closed.
Vacuous if the panel callback never runs or profiling cannot attribute the
allocation. A high overall frame time alone is not evidence for this candidate.

**Falsifier:** the list is consumed by behavior outside the apparent lexical
scope, or profiling shows no meaningful cost; the latter refutes a performance
priority, even though the lexical dead-work tell remains. TAKEABLE WHEN FR-3
profiling (checklist 136) or an appropriate attended ranch fixture is available.
Keep `cand`; no timing result is claimed and no patch is proposed here.
