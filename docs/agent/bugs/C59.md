### C59 — GetNextCrop fails to advance over empty crop slots (P3, no demonstrated player impact) `[cand 2026-09-10: source-read; R4 literal-call search]`

**PASSING. SOURCE intent tell:** bounded dead loop and sibling contradiction.
`Lua/Buildings/Farm.lua` old `GetNextCrop :651-663`, new `:790-802`, initializes
`next_idx = current_crop + 1` and then checks that same index three times.
It wraps values above three but never advances after an empty slot. Actual
`PlantNextCrop` advances correctly: old `:509-520` (increment `:511`), new
`:579-590` (increment `:581`). New display formatting did not cause this defect.

**MEASURED at the desk:** `tools/desk_seam_food.py` executes extracted old/new
helper bodies with `{A, false, B}` and current slot 1: both return `None`.
An adjacent B positive control returns B. Only display helpers and preset
names are stubbed. `reports/vanillahunt/SEAM_DESK.txt` records the result.
The loop finishes after three iterations; it is NOT an infinite loop.

**MEASURED search / SOURCE ROUTE — R4 for literal references:** a full-text
`rg -F GetNextCrop` across both archived base Src trees returns exactly two
declarations and zero other mentions. No player action reaches this helper
in the inspected base code. Dynamic/native invocation is outside that search;
its existence must be shown before assigning player harm. **Non-owner answer:**
the defective helper is base code on both branches, but no ordinary owner or
non-owner trigger was found. P3 is a tracking priority, not observed severity.

**Recipe:** no valid in-game recipe exists from this search. The desk input
above is a function control, not a colonist/farm gameplay reproduction.
Vacuous if only the no-later-crop case is used or an adjacent occupied slot
returns before the loop needs to advance.

**Falsifier:** a complete call route with an invariant that the immediate next
slot is always occupied, or a shipped overriding implementation that makes
the apparent skipped-slot contract inapplicable. TAKEABLE WHEN a concrete
caller is discovered; the terminal audit owns disposition. Do not patch an
unreachable helper just because a desk fixture can call it.
