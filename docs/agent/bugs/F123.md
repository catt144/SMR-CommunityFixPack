### F123 — `Fix_GeneForging` double-pays the repaired technology on 1.1.1 `[filed 2026-09-23: duplicate arithmetic is explicit]`

Archived 1.1.1.405907 `Lua/Units/Colonist.lua:4719-4728` now starts at zero and
adds both researched technologies through their live preset values. The module captures
that function, calls it, then adds Gene Forging again when researched
(`Code/Fix_GeneForging.lua:141-151`). With the recorded parameters, Forging alone
returns 100 instead of 50 and both technologies return 200 instead of 150.

**Repair contract.** Remove the module and all registrations. No saved state is
written, so no cleanup or migration is needed.

**Falsifier.** On 1.1.1 with only Gene Forging researched, call the live function with
the pack on and off. An equal result would refute runtime double payment. The Lua value
flow is complete; the downstream newborn distribution has not been simulated.

**Harm.** During birth/colonist generation, the colony receives more rare traits than
the researched bonuses promise. The effect can compound throughout a long colony; it
does not depend on factories or late resource headroom once the technology is reached.
