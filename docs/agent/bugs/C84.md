### C84 — homeless resettlement may enter an unsupplied dome when a must-have filter forces it (P3) `[wontfix 2026-09-10: intentional]`

**Found by C83's mandatory follow-through trace; not observed in play.** A colonist left
homeless in C83's full working fallback later calls `TryToEmigrate` from the ordinary heavy
update (`Lua/Units/Colonist.lua:2338-2352`, game 1.1.0.403908) →
`FindEmigrationDome` → `BuildReachableGraph` / `GetBestReachableCommunities`
(`:3400-3526`). This path has no `safety_dome` fallback: it chooses only a scored member of
the explicit reachable graph.

**The adjacent shape.** A candidate needs `CanVisit(self)` and
`CanAcceptNewColonists()` (`:3456-3459`). The latter is only `ui_working and
accept_colonists` (`Lua/Buildings/Community.lua:96-98`) — it does not call
`HasLifeSupport`. `Community:GetScoreFor` normally makes a dead candidate lose
(`CommunityEvalLifeSupport = 100`, `CommunityEvalNoLifeSupport = -400`), but a must-have
dome-filter match is 1,000,000 and can override that tier (`:434-445`). Thus a reachable,
switched-on, accepting but unsupplied dome can win when the player made its filter mandatory
for this colonist. The archived 1.0.7 path has the same candidate gate
(`Community.lua:61-63`; `Colonist.lua:2657-2691`) and the same general score ordering.

**Verdict — intentional, not a C83 sibling fix.** The shipped 1.1.0 constant's own help text
says the no-life-support score must remain small enough for a must-have match to override it
“so the player can still force colonists into an unpowered dome”
(`Community.lua:436-440`). A manually forced dome is likewise returned before automatic
selection (`Colonist.lua:3502-3509`). This is a player-authored override, not C83's silent
distance fallback. FIX_POLICY §4 bars changing it; status is `wontfix — intentional`.

**Why C83 stays narrow.** C83 places the overflow homeless in the nearest welcoming dome.
Later movement normally prefers live communities through the score tier; only the explicit
must-have/forced override can undo it. C83's attended leg watched the arrivals for one sol;
nobody moved into the dead quarantined dome, which is not eligible here because
`accept_colonists` is false.
