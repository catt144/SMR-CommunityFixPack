## 2026-09-23 — game 1.1.1 rebase; current mechanism is desk-verified only

The historical sections above retain their original scope. The current module
preserves native migration and repairs both direct and intermediate passage
decisions; [F125](F125.md) records why the 1.1.0 replacement became a pack defect.

**Changed design decision:** the old “No distance pre-wrapper” conclusion applied
to a distance change that could alter several predicates. The new direct wrapper
uses a bounded value only for a positive short vacuum walk between connected
domes. It requires runtime `MaxDomeWalkDist + 1 < MinDistToIgnorePassage`, raises
the value to `MaxDomeWalkDist + 1`, and delegates to native. Thus it crosses the
lookup threshold without entering the `-1` conversion or changing the later
passage-detour choice. No-passage calls and unsafe threshold orders are unchanged.
SOURCE: archived 1.1.1.405907 `Lua/Units/Colonist.lua:1909-1924`; the distance is
not read after that choice. This is a justified departure from the dated local
design, not a reversal of the owner's ck123 instruction to repair the defect.

Intermediate legs use a consumed thread-local marker around synchronous native
helpers; the blocking `MigrateStep` stays native. No new persisted field or
continuation is introduced. The intentional no-passage surface fallback remains.
`python tools/desk_f125_vacuum.py` exercises both sites, controls and scratch
reversals. Its engine shims are not a navigation or save-load measurement.

Current status is **fixed**, not the historical 1.0.7 `tested*`. Owner play is
ck210; commands, limits and internal review are in the
[build report](../reports/GAMEPATCH_1.1.1_BUILD_2026-09-23.md).
