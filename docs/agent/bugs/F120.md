### F120 — Tech-point conversion hides a previously revealed Wildfire cure `[filed 2026-09-16: desk-reproduced migration defect; retail unexercised]`

**MEASURED:** the shipped discovery converter leaves the entire Wildfire family
hidden for a synthetic legacy player with a discovered cure and sufficient tech
points. A second PostLoadGame sweep does not recover it. The same converter
successfully restores a discovered breakthrough control. Command and source
hashes: [desk evidence](../../archive/wildfire_cure_desk_before_20260916.txt).

**INHERITED report:** Steam, Jäger, 2026-09-14, owner-relayed: “I seem to be
having an issue with the Wildfire Mystery, there is no option to research the
cure in the new tech tree.” No save, log, migration history, mod list or mystery
stage was supplied. **This mechanism can produce that symptom; the player's
specific cause remains unconfirmed.** No reporter save is being requested.

#### Cause and reachability

**SOURCE, R2:** a colony that revealed the cure on 1.0.7 and then crosses to
1.1.0 retains `tech_status.WildfireCure.discovered`. The old creator stores
`field = "Mysteries"` (`Lua/Research.lua:668-682`, archived 1.0.7; preset at
`Data/TechPreset.lua:2677-2693`). The scenario's `Field = "Special"` is editor
metadata, not this saved field.

The current converter `SavegameFixups.TechPoints_MigrateDiscoveredSpecialTechs`
(`Lua/TechTree.lua:1486-1502`, 1.1.0.403908) accepts only BuriedWonders,
Storybits and Breakthroughs. It drops Mysteries without an error. Newly created
lock state hides the current cure presets (`CommonLua/Features/LockablePreset.lua`,
`ResetLockablePresetState` and `PreProcessLockablePresets`). A scenario already
past its reveal does not replay that action merely because the game was upgraded.
`SA_WaitResearch:SAExec` continues waiting on the final `WildfireCure`.

**SOURCE intent:** the converter explicitly preserves discovered event research
for sibling groups, and the Wildfire scenario promises an available research
chain. Losing an earned discovery while retaining the waiting scenario violates
both contracts. This benefits ordinary vanilla colonies and needs no other mod.

**MEASURED qualification:** a remaining medical-building grant force-researches
the first intermediate, which reopens the next node. This is a recovery route
only while the saved SpeedUpResearch loop still has a grant available. A save
that used up that loop before conversion has no remaining medical grant to
rescue its hidden chain. Loop exhaustion is a SOURCE condition, not sampled in
a retail colony.

#### Controls and repair contract

**MEASURED:** fresh reveal enables the chain head; sequential purchases reach
the final tech; zero points leave a revealed node visible but unaffordable;
medical grants advance intermediates without spending points; the final tech
still needs a point. `Field = "Special"` does not prevent the completed-tech
wait from returning. These are shipped-body desk results, not UI observations.

**Falsifier:** run the converter and PostLoadGame processing on an old colony
whose cure discovery predates conversion. If a shipped path already restores a
researchable family member, this hidden-family defect is absent for that state.
The harness must retain both that healthy control and the omitted-group case.

**Repair being built:** restore only the existing scenario's chain entrance
when the legacy discovery is positive, the colony is Wildfire, and the entire
current family remains hidden. Follow `MysteryTechRevealRemapping`'s entrance;
do not award research, points, crops, or scenario completion. Existing affected
saves must recover on load; a prevention-only change is insufficient (owner,
2026-09-16). A second load must preserve recovery and skip the already healthy
state. No new persisted field or thread is needed.

**SOURCE class / routing:** the omission is group-wide, so other migrated mystery
discoveries deserve the same question. This entry owns the established Wildfire
member. C79's discarded cost, C69's dead in-progress state, C92's unreachable
technology and C97's tutorial flags share the research rewrite as historical
context, not a demonstrated common repair. None is changed by this finding.
