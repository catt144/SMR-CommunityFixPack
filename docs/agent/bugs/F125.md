walks with a passage cross only the native lookup threshold: the supplied distance
stays positive and strictly below the native passage-detour threshold. The runtime
constant order is checked; unsafe bounds and no-passage calls keep native input.

colonist, command/thread, domes and city must match. The native blocking command,
reservations, task transitions and returns remain in place. A failed global-wrapper
write leaves the class methods untouched.
