### C56 — ranch forecast and harvested Food disagree after per-animal rounding (P3) `[cand 2026-09-10: source-read; desk control only]`

**DIFF-CAUSED. SOURCE intent tell:** sibling contradiction between actual output
and the same ranch's expected-output calculation; this does not establish which
quantity the designers intended. No balance repair is authorized by this entry.

**SOURCE:** 1.1.0 `Lua/Units/Animals.lua:741-764` `Pasture:ProduceFood` applies
`RoundResourceAmountToTenth` to each animal at `:752`. The helper
`Lua/Resources.lua:78-83` rounds to 100 internal units and floors every positive
amount at 100. `CalcExpectedProduction` (`Animals.lua:906-916`) rounds the HERD
total, and `GetUIBreedProductionText` (`:972-997`) multiplies the unquantized
per-animal amount by herd size. Base `Data/Animal.lua:3-25` supplies Chicken:
25 animals, 100 Food internal units each.

**SOURCE old counterpart:** 1.0.7 `Animals.lua:691-696` produces each animal's
scaled `food` without the new quantizer; `:819-826` forecasts the herd. The old
Chicken preset has `food = 200`, so its baseline quantity is different; comparing
actual with forecast WITHIN each branch isolates the discrepancy from that data
change. The removed outdoor overrides `:863-877` use the same old arithmetic;
1.1.0's `OpenPastureBase` inherits the new implementation.

**SOURCE ROUTE — R2:** an operating base Ranch raises a Chicken herd;
`Pasture:BuildingUpdate` (`1.1.0 :655-676`, old `:632-653`) reaches
`KillCurrentHerd(true)` at maturity; new `:701-712` queues every animal's
`Despawn`, whose `:538-549` calls `self.pasture:ProduceFood(self)` (old
`:541-552`, `KillCurrentHerd :678-689`). These are the in-tree dispatch routes
to production; no override of `Pasture:ProduceFood` remains in base 1.1.0.
The forecast route is `Lua/XDef/sectionPasture.generated.lua:32-33` ->
`UIBreedUpdate :1172-1233` (call at `:1188`) -> `GetUIBreedProductionText`
-> `CalcExpectedProduction` (call at `:980`).

**MEASURED at the desk, 2026-09-10:** `python tools/desk_seam_food.py` extracts
both shipped bodies and base Animal preset files. With stable performance 48,
no modifiers, native-food multiplier 100 and an accepting output collector:
old actual/forecast = 2,400/2,400 internal units; new actual/forecast/UI argument =
2,500/1,200/1,200. New performance 0 and 100 controls agree. Replacing the
quantizer with an identity in the isolated harness removes the mismatch.
Evidence output: `reports/vanillahunt/SEAM_DESK.txt`. Native producer storage,
real performance accumulation, renderer and engine rounding are not executed;
integer arithmetic and formatting collectors are named stubs in the harness.

**INFERRED severity:** silent forecast error; a low-performing Chicken herd may
produce materially more Food than advertised. **Non-owners: yes**, the ranch,
Chicken data, helper and both consuming bodies are all base content. No DLC
symbol is needed for this counterexample.

**Independent recipe [NEVER RUN]:** in a fresh 1.1.0 colony, raise Chickens in a
Ranch with limited staffing, record its accumulated performance, forecast and
harvest output before drones remove output. Read the active forecast before
maturity; `killing_herd` changes its UI state during harvesting. Wait for all

Repeat a normally staffed herd.
Vacuous if the output is blocked, herd is killed without produce=true, or
performance/modifiers happen to make each animal a multiple of 100. Do not
require exactly 48 performance organically; measure the actual average.
