### F119 — a landed trade rocket keeps its landing-time fuel request; a fuel-cost change on the pad soft-locks it (P1, source-read — filed)  `[filed 2026-09-11: source-derived, NOT reproduced]`

- ⛔ **STATUS: SOURCE-DERIVED, NEVER REPRODUCED.** No save, no log. Every line below is a desk read of shipped Lua.
- Triage record for all six leads of the day: `reports/FIELD_LEADS_2026-09-11.md`.

#### Field reports (INHERITED — player words, owner screenshots, r/SurvivingMars "Game-breaking bug for the Wildfire mystery on the new version", 2026-09-10/11)

- OP (PS5, Relaunched, Brazil, Wildfire): the cure shipped 2–3 times, then the latest Earth cargo rocket "refuses to
  leave the landing pad. All the crops are on board, but it says there's 20 fuel to unload." Nothing removes it; it is
  not the player's rocket. The OP has Advanced Martian Engines researched.
- A second player (PC, Brazil, Wildfire): "stuck with 20/30 required fuel and full of curetatoes"; manual drone control
  and an RC Transport both fail; drones still recharge batteries at it.

#### The mechanism (SOURCE, game 1.1.0.403908 unless marked)

1. The cure rocket is a `UniversalTradeRocket` with `RocketType = g_RocketTypes.Trade`
   (`Lua/Sequences/SA_Gameplay.lua:2851-2861`), spawned by Mystery 8 with `rocket_id = "CureRocket"`, 60 Wildfire Cure and
   no `fuel_amount` (`Lua/Scenario/Mystery 8.generated.lua:824-831`), so its launch fuel is the template's 50
   (`Data/BuildingTemplate/UniversalTradeRocket.lua:4`, `50000`) plus any `AllRockets` label modifiers.
2. On landing, the `our_colony` policy's Trade branch swaps the flight data and starts `CmdLoad`
   (`Data/FlightPolicyDef.lua:561-568`) → `SetCargoRequest` → `CargoTransporterNew:UpdateCargoResourceRequests`
   (`Lua/CargoTransporterNew.lua:1484`). That sizes the fuel requests ONCE: `requested + GetFuelResourceRequest() − amount`
   goes into the demand request if positive, the supply request if negative (`:1442-1458`).
3. `GetFuelResourceRequest` returns the LIVE `FuelResourceAmount` (`Lua/UniversalRocket.lua:1891-1908`). After the swap
   the arrival is Earth, and the `earth` policy has no `OnGetFuelResourceRequest`: overrides exist only for anomaly
   (`FlightPolicyDef.lua:44`), asteroid (`:247`), our_colony (`:596`) and rival (`:829`), and the policy is chosen by
   arrival type (`Lua/ClassDefs/ClassDef-Default.generated.lua:89-97`).
4. The ONLY re-size on a fuel-cost change is gated on player control: `OnModifiableValueChanged` calls
   `UpdateCargoResourceRequests` only `if prop == "FuelResourceAmount" and self:IsPlayerControlled() and self.cargo`
   (`UniversalRocket.lua:1916-1920`), and `IsPlayerControlled` excludes `Trade` (`:2631-2638`). Every other caller is
   one-shot or a button (`:580`, `:774`, `:2619` `AppendCargo`, `:3322` `ToggleRefuel`, `:3351` `ToggleReturnFuel`).
   `ToggleRefuel` is offered only on player-controlled rockets (`:3328`), and the trade rocket's own panel
   (`Lua/XDef/customUniversalTradeRocket.generated.lua`) has no buttons (0 `OnPress` / `func =` / `SetVisible` hits).
5. Readiness reads the LIVE requirement: `GetCargoResourcesStatus` returns `"unloading"` when fuel aboard exceeds
   `requested + GetFuelResourceRequest()` and `"loading"` when below (`CargoTransporterNew.lua:1288-1306`); `IsCargoReady`
   needs `"ready"` (`UniversalRocket.lua:558`) and `CmdLoad` spins on it (`:500-502`).

**ROUTE (INFERRED from 1–5):** a fuel-cost DROP while the rocket is landed leaves surplus aboard → status `"unloading"`,
but the supply request was sized at 0 → nothing ever unloads → no launch. A RISE leaves a shortfall → `"loading"` with
the demand already 0 → no drone brings fuel → no launch. Either way it waits forever. The panel lists the surplus as cargo
to unload (INHERITED: `XDef/customUniversalRocket.generated.lua:319-333`, investigator read).

#### Fix sketch (PROPOSED, not built — checklist 146)

- Post-wrap `UniversalRocketBase:OnModifiableValueChanged`: when `prop == "FuelResourceAmount"`, the rocket is landed
  with `self.cargo`, and it is NOT player-controlled, call `self:UpdateCargoResourceRequests()` — the game's own method,
  the same call the player branch already makes.
- A load-time heal for saves already stuck: each landed `Trade` rocket in `CmdLoad` whose fuel status is not ready gets
  one `UpdateCargoResourceRequests()`.
- `FIX_POLICY` §2a behaviour guard; §3a save-safety (calls a vanilla method, stores nothing). A Beta label until
  attended (the fixtoggles chain asked, 2026-09-11).
