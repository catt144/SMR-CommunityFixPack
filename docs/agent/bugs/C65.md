### C65 — the retained Earth Council intro path is orphaned `[cand 2026-09-10: source-read; runtime unobserved]`

**DIFF-CAUSED. SOURCE intent tell:** a retained and newly modified feature path
has no remaining literal caller. Old `Lua/Factions/Legislature.lua`
`OpenFirstLegislatureSessionPopup :227-238` was called by
`Legislature:BeginSession :258`. `BeginSession` was removed. The new popup body
at `:279-290` even adds `Msg("FirstLegislatureSessionPopupClosed")`, but an
exhaustive pinned-tree search finds only the declaration and no listener for
that message. The shipped `EarthCouncilIntro` preset remains in
`Data/PopupNotifications/PopupNotificationPreset-Laws.lua:38-48`.

**SOURCE ROUTE — R1, ordinary base/non-owner politics:** on a fresh
politics-enabled sponsor-faction colony, the first usable Earth Council state
no longer has a Lua call that presents its introductory popup. No DLC class or
preset is involved.

**MEASURED source control, not runtime:** `tools/desk_progress_seam.py` verifies
that the old file has the declaration plus the BeginSession call, while the new
file has the declaration only; it also verifies the popup preset still exists.
This proves the literal Lua orphan, not the absence of dynamic/native dispatch.

**INFERRED severity:** feature onboarding and the offered jump to Elections can
be lost. No gameplay state corruption is claimed.

**Independent recipe / falsifier:** start a fresh eligible 1.1 sponsor-faction
politics game and reach first Council availability while counting calls to
`OpenFirstLegislatureSessionPopup`; observe whether `EarthCouncilIntro` appears.
Manually invoke the wrapper in the same state as the positive display control.
Vacuous under tutorial, NoPolitics, a non-sponsor faction setup, or if first
availability is never reached. Any native or dynamically constructed call by
name falsifies the orphan conclusion. No fix is proposed.
