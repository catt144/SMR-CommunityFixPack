#### The route (1.1.0)

`TrackAllMoments(obj, fx_action, fx_actor, fx_target)` (`Lua/Buildings/Building.lua:3364`)
reads the moment names from `GetAllAnimMoments(obj)` (`:3346-3362`, which converts
the index with `GetStateName`, so this tracker is NOT C74's index bug), then waits on
`TypeOfMoment`/`TimeToMoment` (`:3372-3383`). Every one of those ends in
`GetEntityAnimMoments`, which reads only `Presets.AnimMetadata[<anim entity>][<anim>]`
(`CommonLua/Classes/AnimMoment.lua:5-16`, `:35-37`, `:304-331`; `EF-086`). Only 5
groups ship (`AdvancedStirlingGenerator`, `BakeryHands`, three `CaveIn_*`), none of
these entities. ⇒ `GetAllAnimMoments` = `{}`, `TypeOfMoment(1,1)` = `""`, and the
thread exits at once (`:3372-3379`): silent, no error.
