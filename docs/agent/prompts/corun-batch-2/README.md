## ⭐ Ordering rule (BINDING — owner, 2026-08-05, on this chain's design)

> *"try to chain them the simplist first so that if we run into somthing that
> requires a course change we don't burn up all our context on the first or
> 2nd task"*

⇒ **Simplest and cheapest legs run FIRST**; the expensive and destructive ones
run late, so an early course change (an owner lead, a broken fixture, a stop
condition) costs the fewest banked results and the least context. This
composes with the standing rule — reads first, mutations later,
**process-mutations dead last** (PT-53's uninstall half ends the sitting; after
it no pack leg is valid). **Bank incrementally:** the sitting records each
leg's card/verdict THE MOMENT the leg completes, so a course change or
self-split loses nothing already earned.

## Binding chain rules

1. **Staleness check first, every prompt**: `git log --oneline -10` +
   `git pull`.
2. **Inbox/outbox in writing.** Each prompt appends its handoff to the next
   prompt's `## Notes from upstream`, commits, deletes its own file in the
   same commit. Folder emptiness is prompt 3's done-condition.
3. **Route, don't drop**; unsure who owns a discovery → STOP AND ASK.
4. **Self-split at a clean commit boundary** if context runs short — and
   because results are banked incrementally (ordering rule above), a split
   loses nothing.
5. **Drift-evidence capture** — disagreements with the record are corrected
   visibly, never silently.
6. **WORKFLOW elements 1–8 bind** (live todo list; declared read path), plus
   the FULL Co-runs section including the 2026-08-05 attended rules and the
   owner-override rule. The estimate in the brief INCLUDES console driving.
7. **FIX_POLICY §3a**: staged COPY (`Copy-Item`, game closed); the campaign
   save is never written; copies + throwaway saves die in the recording
   commit (leg S's FIXTURE save is the one survivor).
8. **Probe hygiene binds unchanged** — sources parked here as `.lua.txt`
   (resurrect batch-1's corrected sources from git `530df63`, do not rewrite);
   files in `Code/` only while the run happens; C11 + its piping corollary;
   ARM GATE before every launch; `PROBE SWEEP:` line in every result commit;
   R8 `git add -f` for every cited log; parked `.ps1` carries a BOM.
9. **doccheck green before every doc commit**; STATE 60-line cap; commits via
   `git commit -F <file>`; parse sweep before any commit touching Lua; push.
   ⚠️ PS 5.1 `Get-Content`/`Set-Content` mangles the repo's no-BOM UTF-8 docs —
   use `[System.IO.File]` with `UTF8Encoding($false)` for any scripted rewrite.
10. **⛔ NO ASSUMED CAPABILITY.** The one `[NEVER RUN]` execution this chain
    makes (`StartBombard`) follows the first-execution discipline: cheap
    dedicated verify BEFORE the leg leans on it; failure → routed gap, not
    improvisation.
11. **⛔ The forced-vs-organic rule**: every finding names what was forced.
    Leg Q forces BOTH halves and says so; leg R's bombardment is a forced
    upstream condition, the volley behaviour stays the game's own.
12. **⛔ ANTI-SPRAWL.** No new standing document, folder, or document class.
    Results land on entries, the checklist, HELP markers, `SESSION_LOG.md`.
13. **Sign-off runs on the ADOPTED tiers**; `tested` still means a pass at the
    keyboard — a co-run pass the owner witnesses CAN earn it; a log-only
    result cannot. The audit enforces the tier, never upgrades it.
14. **⭐ Kickoff + next-chain handoff.** Prompt 3's owner report ENDS with the
    next-chain kickoff line (source: `STATE.md` NEXT; nothing queued → say
    so). Mid-sitting, owner minutes beyond the estimate are the owner's live
    call — record actuals against the estimate either way, and score only the
    rig's own misses (owner override rule, 2026-08-05).

## Stop conditions (chain-wide)

- A fixture confirm fails in prep → that leg becomes `SKIP <reason>` in the
  brief; the sitting runs the rest. Two or more core legs dead → route to the
  owner before scheduling the sitting.
- Any `[LUA ERROR]` naming pack code mid-sitting → stop the leg, record
  verbatim, continue with independent legs if the game state allows.
- The owner has to leave → finish the current leg's read, save nothing
  unplanned, record what ran; the remainder stays TAKEABLE IN the next co-run.
  An honestly-closed partial sitting beats a rushed one — batch-1 proved the
  ordering rule's value; simplest-first means the banked results are maximal.
- Leg T, once started, is not interleaved with anything — it is last precisely
  so a stop there costs nothing else.
